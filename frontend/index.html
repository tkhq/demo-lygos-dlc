Turnkey Verifiable Cloud / Lygos

Verifying a Bitcoin loan inside an enclave

A Rust app in a Turnkey Verifiable Cloud enclave decodes a Lygos DLC, checks every signature, confirms the contract encodes the terms you agreed to, and — where it matters — proves the collateral is locked on Bitcoin. It signs the verdict with a key sealed to the approved binary.

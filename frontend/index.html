DLC Verification Inside an Enclave

A Rust app running in a Turnkey Verifiable Cloud enclave parses a Lygos loan contract, checks the oracle's announcement signature and every CET adaptor signature, then looks the collateral transaction up on Bitcoin — and signs the verdict with a key sealed to the approved binary.
